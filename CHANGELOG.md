# Changelog

## 0.1.0 source prototype

- Checkpoint 1: pure board/arrow engine, level codec, greedy solver, one-level scene and engine test definitions.
- Checkpoint 2: guaranteed-solvable authoring, difficulty estimates, 30 JSON levels and independent validation.
- Checkpoint 3: campaign UI, scoring, local progress, animated feedback, original audio, Android haptic calls and Godot runtime test definitions.
- Checkpoint 4: Android export preset, CI build workflow, original launcher icons and explicit verification/device handoff.

Godot execution and APK export remain blocked in the authoring environment. No Android release has been built or published.
